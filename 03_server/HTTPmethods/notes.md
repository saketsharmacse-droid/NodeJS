# HTTP Methods

- get
- post
- put
- patch
- delete

- GET: when you want to get some data from the server, toh get type ki request krenge.
- jab hum browser mei url likhte hai toh wo by default get request krta hai server ko.
- get humse expect krega ki hum kuch request krr rhe hais erver se
- usually we are reading data from the database, server handles these requests.
- get se hum kuch maang rhe hai from the server

- POST: when you want to send and mutate data over the server
- jab humein send krke uss data ko save krwana hai, database mei enter krwana hai.
- like if there is a form, uske data ko hum chahte hai ki server le aur database mei ek jagah store krr de, so we use the post method.
- mutate mtlab changes krnma data mei.
- post request ke saath ek db query bhi jayegi, jo server krga, database mei data insert krne ke lioye
- post sends data and saves it over the database.

- PUT: if kisi form mei photo yaa file upload krr rhe toh put is used
- put mtlab basically server pe database pe kuch file/data put krna

- PATCH: patch mtlab already entered value ko changes krna
- jaise existing entry ko change krna: like changing a saved usernme

- DELETE: yeh delete krta hai records ko, saved data ko.
